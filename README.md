# 💛 DEEPU • Heirloom Keepsake Memory Album & 3D Flip-Book

A luxury celestial digital flip-book and memory keepsake gift created for best friend **Deepu**. Built with plain HTML5, CSS3 3D transforms, JavaScript, and Tailwind CSS.

---

## ✨ Features & Experience Flow

1. **Cover Screen (Heirloom Celestial Hardcover)**:
   - Deep celestial midnight palette (`#0b1325`) with ambient starlight dust.
   - Realistic 3D book perspective with ornate brass corner protectors, velvet ribbon bookmark, and leather spine indentation.
   - Deepu's hero keepsake portrait artwork.
   - Gilded title **DEEPU** with botanical stamped motif.
   - Glowing interactive **"Open Memory Album"** button.

2. **3D Book Opening Transition**:
   - On tap/click, the leather spine creaks and the pages flutter with realistic synthesized sounds.
   - 3D perspective cover swing opens smoothly into the open photo album spread with golden confetti bursts!
   - Background song starts playing automatically.

3. **18 Unique Handcrafted Photo Spreads**:
   - **Left Page**: Deepu's photos presented in 18 distinct handcrafted artistic styles:
     1. *Vintage Coffee Polaroid* (peach washi tape & gold tabs)
     2. *Kodak Gold 35mm Film Strip* (authentic sprockets & frame numbers)
     3. *Pressed Botanical Herbarium* (flora & olive leaf accents)
     4. *Airmail Vintage Postcard* (postal cancel stamp & airmail chevrons)
     5. *Fairy Lights Cozy Frame* (warm glowing fairy lights)
     6. *Scrapbook Ticket Stub* (metallic paperclip & vintage concert stub)
     7. *Retro Cassette Mixtape* (90s tape layout)
     8. *Sunflower Sunshine* (watercolor golden sunflower blooms)
     9. *Pinky Promise* (pastel blush ribbon border)
     10. *Golden Celebration* (champagne gold foil sparkles)
     11. *Newspaper Chronicle* (vintage newspaper edition)
     12. *Cozy Cottagecore* (lace embroidery & lavender)
     13. *Celestial Constellation* (midnight galaxy & moon phases)
     14. *Retro Polaroid Grid* (quad memory collage)
     15. *Antique Journal* (leather journal border)
     16. *Ocean Breeze* (sea glass azure border)
     17. *Butterfly Garden* (monarch watercolor wings)
     18. *Timeless Heirloom* (regal gilded gold frame)
   - Every photo includes full-resolution lightbox zoom on tap.
   - **Right Page**: Dedication chapter tag, custom heartfelt line, and sub-note.
   - **Page Navigation**: `[Next Page ➔]` / `[← Previous]` buttons, keyboard arrow keys (`←`/`→`), touch swipe gestures, and an 18-dot thumbnail strip to jump anywhere instantly.

4. **Background Music**:
   - Background soundtrack: **"Beautiful" by Amit Trivedi** (*from Goodbye*).
   - Audio toggle pill in the top header.

5. **Grand Finale Letter**:
   - Personalized heartfelt letter to Deepu with handwritten script and gold foil details:
     *"Oye Kubhkaran Deepu... Tera lifetime punching bag 🥊"*
   - Interactive *"Replay from Page 1"* with celebratory confetti.

## 🚀 Running Locally

Open in your browser:
👉 **`http://localhost:8000`**

To start the local server anytime:
```bash
python -m http.server 8000
```

---

## 🌐 Deploy Free (GitHub Pages)

1. Go to repository settings on GitHub: **Settings** → **Pages**.
2. Under **Build and deployment**, select:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`), folder: `/ (root)`
3. Click **Save**. Your site will be live at:
   `https://harshnintindo.github.io/deepu/`
