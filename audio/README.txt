🎵 Background Music Folder:

To play your own background music:
1. Place your audio file here (for example: `music.mp3`, `song.mp3`, or `m4a`).
2. Make sure the filename matches `music.audioSrc` in `js/config.js` (default: "audio/music.mp3").
3. Supported formats: .mp3, .wav, .m4a, .ogg.

Note:
If no audio file is provided or if loading fails, the web app automatically falls back to an enchanting, gentle piano/chime lullaby using the browser's built-in Web Audio API, so music will always work seamlessly!
